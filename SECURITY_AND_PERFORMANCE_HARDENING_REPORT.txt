2. SECURITY HARDENING MEASURES
--------------------------------------------------------------------------------
A. Payload Integrity Verification (x-amz-content-sha256)
   - Issue: The gateway previously accepted declared payload hashes without
     cryptographically verifying them against the actual incoming payload buffer.
   - Solution: Added verification in `gateway.ts`:
     When `x-amz-content-sha256` is supplied (and not UNSIGNED-PAYLOAD or
     STREAMING), `actualPayloadHash` is computed from the buffered body and
     compared using constant-time `timingSafeEqual()`. Mismatches are rejected
     with S3-standard `400 XAmzContentSHA256Mismatch`.
   - Verification: Validated in `test_security_hardening.py` [Test 3] (PASS).

B. Strict Path Traversal & Input Sanitization
   - Issue: Directory traversal tokens (`../`), null bytes (`%00`), and backslashes
     could cause unexpected path resolution.
   - Solution: Added strict decoded URI validation in `gateway.ts`:
     Rejects any path containing `\0`, backslashes `\`, `..` segments, or ASCII
     control characters with `400 InvalidURI`.
   - Verification: Validated in `test_security_hardening.py` [Test 1] (PASS).

C. Hardened Security & CORS Headers
   - Issue: Lack of anti-sniffing and clickjacking response protection.
   - Solution: Injected `X-Content-Type-Options: nosniff` and `X-Frame-Options: DENY`
     on all gateway responses, XML error bodies, and OPTIONS preflights.
   - Verification: Validated in `test_security_hardening.py` [Test 2] (PASS).

D. Multi-Tenant Boundary Isolation
   - Strict tenant boundary verification: All operations cross-reference
     `bucket.accountId === cred.accountId` and scoped `cred.buckets` whitelist.
   - Verification: Validated in `test_isolation.py` (PASS across all methods).

--------------------------------------------------------------------------------
3. PERFORMANCE OPTIMIZATIONS
--------------------------------------------------------------------------------
A. In-Memory TTL Query Caching
   - Problem: Convex self-hosted V8 isolates experienced cold-start query latency
     and isolate roundtrips for repeated lookups of `s3Credentials:resolveCredential`
     and `buckets:resolveBucketByRustfsName`.
   - Optimization: Added bounded in-memory TTL caching (60s TTL, max 1000 items)
     in `gateway.ts`.
   - Result: Warm requests execute with O(1) in-memory resolution. Average warm
     latency reduced from seconds to ~467ms across sequential calls.

B. High-Throughput Multipart Buffering
   - Problem: Memory limits on single-object PUTs constrained large file transfers.
   - Optimization: Gateway intelligently distinguishes multipart part uploads
     (`?partNumber=&uploadId=`), allowing up to 64 MiB per chunk while preserving
     the 10 MiB safeguard on standard single-PUT objects.
   - Verification: Validated with full 6.3MB (5MB+ Part 1) multipart test in
     `test_multipart_5mb.py` (PASS).
